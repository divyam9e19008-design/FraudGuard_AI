The core challenge: severe imbalance

Out of 200,000 applications, only about 2,200 are fraudulent. A model can score 99% accuracy by simply calling everything “safe” — and catch zero fraud. The real task is finding the needles without burying reviewers in false alarms.

The accuracy trap

A model that predicts "not fraud" for every application still scores 99% accuracy — while catching nothing. That’s why this project is judged on recall, precision and F1, not accuracy.

ENGINEERING INTEGRITY

The 0.94 F1 that wasn’t real.

An early grid-search reported a stunning 0.945 F1 — far too good for a 1% fraud rate. On inspection it came from data leakage: oversampling before the train/test split let the model peek at test data. Caught, corrected, and re-evaluated honestly. A number that survives scrutiny beats a beautiful one that doesn’t.
